what minimal_text is not
  • — a second accent, or accent as decoration
  • — color in the intensity encoding (magnitude only)
  • — images, photos, illustrations, hero art
  • — box-shadow
  • — border-radius (except the 3px pill)
  • — font-weight 700+ / bold
  • — text-transform: uppercase
  • — gradients, rgba() overlays, blur
  • — scroll-triggered animation / bounces / loops
  • — emoji, icon fonts, decorative glyphs
  • — framework UI libraries / utility soup

built from restraint — the most important control is the one you don’t add.
